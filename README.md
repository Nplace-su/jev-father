# Jev Judger · 从夯到拉

用 Jev 评价基于 Jev 的项目。娱乐法庭，只审项目，不审人。

输入一个公开 GitHub 仓库链接，读取范围内的全部源码、文档和配置，用 Jev 的结构化选择来判断：这次到底是用在刀刃上，还是强行接入？机器人项目加试职责边界。

## 在自己电脑上使用

这是本地应用：GitHub 提供源码下载，本机 Node.js 服务负责调用 GitHub 和 Jev，浏览器负责交互。不需要购买服务器、部署云后端或安装依赖。只评公开 GitHub 仓库。

1. 安装 [Node.js LTS](https://nodejs.org/)（最低 20.12）。
2. 在仓库页面选择 **Code → Download ZIP**，解压到一个文件夹；也可以 `git clone`。
3. Windows 双击 `start.cmd`；macOS 双击 `start.command`。浏览器会自动打开 <http://localhost:3210>。
4. 在页面填写自己的 Jev API key 和公开 GitHub 仓库链接，点击「即刻开庭」。不填 Key 也可以看虚构示例。

macOS 如果无法双击执行，或使用 Linux，在解压目录打开终端运行：

```sh
npm start
```

没有第三方依赖，**无需 `npm install`，无需先配置 `.env`**。使用期间保持启动终端开启；按 Ctrl+C 停止服务。自动打开浏览器失败时，手动访问终端显示的网址。服务器只监听 `127.0.0.1`，同一局域网的其他设备无法访问。

### Key 怎么处理

页面填写的 Key 提交后清空，仅随本次评审交给**自己电脑上的本地服务**，再作为鉴权发送给 `api.typesafe.ai`。应用不将它写入文件、浏览器存储、日志或评审导出，也不通过作者的服务器。它不会被用于 GitHub 请求。评审失败后重试需要重新填写。

如希望在自己电脑上长期保存配置，可自行复制 `.env.example` 为 `.env` 并填写 `TYPESAFE_API_KEY`；这是可选的持久保存方式，修改后重启。页面填写的 Key 优先于 `.env`，仅覆盖本次。`.env` 已被 Git 忽略，不要分享该文件。

GitHub 优先使用可选的 `GITHUB_TOKEN`，否则尝试复用本机 `gh auth login`，再退回匿名访问；仍拒绝私有仓库。匿名 API 额度耗尽时，按错误提示配置 GitHub token 或稍后重试。`JEV_MODEL` 默认 `jev-latest`，`PORT` 默认 `3210`；端口被占用时可在 `.env` 修改。设置 `JEV_NO_OPEN=1` 可以禁用自动打开浏览器。

### 为什么不是 GitHub Pages

纯静态网页需要 Jev 接口允许浏览器跨域调用。2026-09-23 对计划使用的 GitHub Pages 来源进行预检时，Jev 返回 `Disallowed CORS origin`。当前发布方式因此是下载后本地启动；本地服务发送 API 请求，不依赖浏览器到 Jev 的跨域许可。仓库若仍为私有，仅有访问权限的人能下载，面向所有人发布需要公开源码或另行提供可公开下载的发布包。

## Jev native 的全文 harness

```text
GitHub URL
  → 固定默认分支 commit，列出完整目录
  → 全文读取相关源码 / 文档 / 配置（不限制为 8 个文件）
  → 外部资料存档 / 精确去重 / 长 JSONL 全行统计
  → 源码、文档全文与日志统计按约 24,000 字符分批
  → 每批一次请求：5 个维度 Choice + 5 个来源片段 Choice（最多 3 批并发）
      适配度 / Jev 的用途 / 实质增量 / 宣传边界 / 机器人职责
  → 保留每个不同判断及其来源片段，最多一次 Jev Choice 全项目复核
  → 最后一个 Jev Choice：夯 / 顶级 / 人上人 / NPC / 拉
  → 程序展示概率、档位和对应预写短评
```

最终档位直接采用最后一个 Jev Choice，**没有加权总分、没有聊天模型、没有第六个弃权档**。低置信度的分项判断及其概率仍交给汇总和终审，不再转换为 unknown。分项仍允许标识本批未涉及，避免把“没在某个文件看见”变成“项目没有”；这不阻止终审在五档中选择。置信度低于 0.45 时仅在页面提示摇摆，不删掉判断。此阈值是娱乐产品的提示规则，不是正确率保证。

一个小仓库只需读一批再终审；多批仓库是 **阅读批次数 + 2 次**（一次复核、一次终审）。同一请求内的多个 Choice 不会各自发 HTTP 请求，state 只摄入一次。README 不再重复附加到每批。全项目复核保留每个维度的每种判断、概率和一份原文片段，批次个数不是投票；其余原文和回答在导出中可查。这种有界复核仍可能漏掉跨文件联系，不等同于完整调用图分析。

评分以 Jev 的额外价值为中心：普通 API/UI 封装默认 NPC；有实际用途的非平凡集成可以是人上人；顶级需要合理基线支持的增益，夯还需要显著且稳健的增益。缺少基线不等于拉，拉需要明确的不适配、劣化或严重夸大。每个维度只按本批实质证据判断，unknown 保留为未涉及；最终仍只五选一，不用代码强行封顶或定档。机器人项目不强制真机，不因仿真扣分，但安全控制器的存在不等于 Jev 的职责就合理；已有规划、感知和控制器能力不算作者或 Jev 的新贡献。

材料准备规则公开在页面清单和 JSON：`context/sources`、`docs/sources`、`third_party`、`external`、`vendor` 等目录按外部背景存档，不送作项目贡献证据；这是目录启发式，可能误识别。其余内容 SHA-256 精确去重。超过 30,000 字符的有效 JSONL 按已知实验条件分组，全部行参与数量、错误、数值指标和已提供 truth 的比较统计，并附首尾及错误样例；无法解析、条件过多或压缩不明显时回退全文。统计不包含所有字符串和完整分布，不证明因果增益。原文件完整保留，可下载复查。

页面展示**全部阶段合计**的输入/输出 token 和估算费用，而非只显示终审。按 [官方 Jev 1.13 定价](https://docs.typesafe.ai/models)（2026-09-23）：输入 $0.042 / 百万 token，输出免费，估算费用 = 总 input tokens × 0.042 / 1,000,000。失败请求不在成功结果统计内，实际扣费以账户为准。

## 轻量边界

- 只受理公开 GitHub 仓库首页，暂不支持子目录、指定分支、私有仓库。
- 扫描全目录，读取支持格式的源码、文档、配置和小型实验表格；单文件最多 1 MB。排除依赖目录、构建产物、锁文件、环境配置、符号链接和非支持类型（如图片、权重）。页面列出排除路径和原因、实际已读 / 范围内文件数及失败路径。
- 长文本按完整内容分块，不截掉文件尾部。当前一次最多 1000 个相关文件、合计 4 MB；超出范围或 GitHub 目录被截断时直接报处理错误，不偷偷回退到抽样。部分文件网络读取失败时仍可评价已读部分，同时明确显示缺失。
- 不下载执行仓库，不自动打开其外链，不做查重或全面新颖性检索；不能证明抄袭、真机效果或性能优势。
- 待评材料和评分指令分开；提示模型忽略仓库内指令。提示注入仍是模型局限，不把这个玩具当严肃审计。
- 调用次数随文本量增长，无自动重试。页面实时显示读取与审阅进度，可以展开各阶段的原始请求 / 回答及 token usage，或下载完整 JSON。导出不含 API key；调用失败时报错，不伪造档位。
- 服务只监听本机，拒绝跨站请求，同时只审一个项目；目前没有部署鉴权、数据库或历史记录。

## 验证

```sh
npm test
```

测试覆盖页面 Key 单次使用与错误路径、配置回退、跨站拒绝、URL 边界、全文件选择、全文分块无丢失、commit 固定、排除与失败项、低置信度保留、单次复核与正反证据保留、去重与全行日志统计、并发上限、接口失败及严格五档 Choice。离线测试使用 fixture，不证明真实 Jev 的判断质量；真实连通性需要自己的 API key。

核心文件：`lib/github.mjs` 取证，`lib/rubric.mjs` 题目与短评，`lib/prepare.mjs` 材料准备，`lib/judge.mjs` 分批与复核接口，`public/` 页面。

官方接口依据（2026-09-23 核对）：[HTTP API](https://docs.typesafe.ai/api)、[Choice](https://docs.typesafe.ai/primitives/choice)、[原子问题与代码组合](https://docs.typesafe.ai/introduction)。
